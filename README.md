# Luminary 2048 🎮

一款设计优雅、界面极具圆润美感、支持多色调自由切换的现代 2048 益智网页游戏。基于 **React 19**、**TypeScript** 与 **Tailwind CSS** 构建，带来丝滑饱满的交互动效与纯净的视觉享受。

---

## ✨ 核心特色

### 🎨 纯粹视觉色调色盘 + ☀️/🌙 日夜间模式一键切换
- **纯粹色彩圆环**：界面全面去除繁冗的文字色调名称，采用高质感纯色圆点交互，让视觉焦点完全回归方块色彩本身。
- **合并优化亮色系**：合并/精简了原先仅有明暗区别的冗余主题，精选出 6 款各具辨识度的鲜活高明度色系（琥珀金、冰川蓝、抹茶绿、蜜桃粉、紫藤罗、落日橙）。
- **专属日/夜间模式切换**：
  - 新增一键日/夜间模式切换开关（全站统一使用精致矢量 **SVG** 图标：☀️ 太阳 / 🌙 月亮）；
  - **日间模式**：清爽明亮、高对比度的柔和采光背景；
  - **夜间模式**：深度护眼的暗黑沉浸质感，高对比荧光数字方块与深色卡片；
  - 用户的色调与日夜偏好自动持久化保存。

---

### 🫧 极具圆润的触感美学
- **饱满圆润方块**：棋盘外框、背景槽位与数字方块均采用大曲率圆角设计（`rounded-3xl` / `rounded-2xl`），带来如同软糖般的视觉质感。
- **生动物理动效**：
  - 新生成方块带有 Q 弹入场动效（Pop In）；
  - 合成相同数字时触发弹性挤压跳跃（Merge Bounce）；
  - 得分时实时上浮飘字（`+4`、`+8`……）；
  - 色调切换时全场方块平滑淡入渐变（Crossfade Transitions）。

---

### ↩️ 支持多次连续撤销
- 底层维护了可回溯至最多 **60 步**的历史操作快照栈（包含棋盘与对应分数）。
- 玩家只要发生过滑块移动，即可随时无限次回退失误走法，无需担心手滑打断高分节奏。

---

### 🎵 原生 Web Audio 纯代码音效
- 纯代码利用浏览器原生 **Web Audio API** 振荡器实时合成轻柔提示音，无需加载任何外部音频文件：
  - **滑动音效**：轻快短促的低频微风声；
  - **合成音效**：清脆悦耳的泡泡声，且音调随着合成数值的翻倍逐级升高；
  - **通关音效**：达成 2048 时的多音符和弦胜出提示；
  - 提供一键静音切换，偏好自动持久化。

---

### 💾 全能存档与数据备份
- **浏览器快速存档**：一键将当前对局存入本地存储（Local Storage）。
- **存档代码分享**：生成轻量 Base64 存档字符，便于复制粘贴转移进度。
- **JSON 文件导入与导出**：支持一键导出包含历史快照的 `.json` 备份文件，换设备随时导入恢复。

---

### 🌐 纯净矢量设计
- 全站界面彻底摒弃系统 emoji，所有功能图标（撤销、新游戏、调色盘、齿轮设置、磁盘存档、音效、语言、胜利奖杯等）统一采用极简利落的 **SVG 矢量图标**，视觉风格高度一体化。
- **中英双语支持**：支持简体中文与 English 一键即时无缝切换。

## 🕹️ 游戏规则与操作指南

### 游戏规则
1. 棋盘为 $4 \times 4$ 网格，每次移动会在随机空白格子生成一个数字（2 或 4）。
2. 当两个具有相同数值的方块发生碰撞时，它们会融合成一个数值翻倍的新方块。
3. 尽可能在棋盘被填满前合成出 **2048** 甚至更高数值（4096、8192…）。
4. 达成 2048 后，可选择继续挑战更高无尽极限！

### 控制方式
- **键盘操作**：方向键（`↑` `↓` `←` `→`）或 `W` `A` `S` `D`。
- **触摸操作**：在手机或触屏设备上直接向上下左右滑动屏幕。

- **框架**：React 19 + TypeScript
- **构建工具**：Vite 6

## 🚀 本地开发与构建

### 环境要求
- Node.js (推荐 v18 及以上)
- npm / yarn / pnpm / bun

### 启动项目
```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器
npm run dev

# 3. 打包生产版本
npm run build
```
在浏览器中打开 `http://localhost:3000` 即可开始游玩。

## 🌐 部署至 GitHub Pages（告别白屏，无需 GitHub Actions）

为什么在 AI Studio 正常，而直接推送到 GitHub Pages 会白屏？
> **核心原因（绝非浏览器兼容问题）**：AI Studio 内部运行了 Node.js Vite 开发服务器，会在请求时实时将 TypeScript/React（`index.tsx`）编译为浏览器可执行的 JavaScript。而 GitHub Pages 是纯静态文件服务器，没有任何 Node.js 编译环境，**任何浏览器都无法直接解析 `.tsx` 源代码**。

本项目已专门配置，**无需编写或运行任何 GitHub Actions 工作流**，即可通过 GitHub 自带的自动部署直接运行：

### 部署配置方式（GitHub 仓库内设置）
1. 确保已将项目（包含编译好的 `docs` 目录及 `assets` 目录）推送到 GitHub 仓库；
2. 打开 GitHub 仓库页面，点击上方的 **Settings**（设置）；
3. 在左侧菜单栏点击 **Pages**；
4. 在 **Build and deployment** 下：
   - **Source** 保持默认的 **`Deploy from a branch`**；
   - **Branch** 选择 **`main`**（或 `master`）；
   - **文件夹下拉框**：
     - **推荐方式**：选择 **`/docs`** 目录（官方专为静态站点设计的发布目录，最稳定）；
     - **根目录方式**：即使保持 **`/(root)`**，根目录中的 `index.html` 也已配置了自动加载编译产物与重定向逻辑；
5. 点击 **Save**（保存）；
6. 每次您向该分支推送更改时，GitHub 都会在后台自动重新部署，1~2 分钟后刷新页面即可顺畅游玩！
